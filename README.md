# Educational-Institute-Registration-Form-Management-Using-Python
This project provides a GUI-based system to register students for courses, storing the data in a MySQL database and also exporting it to an Excel file. It is built using Python with Tkinter for the interface, pymysql for database connectivity, and openpyxl for Excel handling.

⚙️ Technologies Used
- Python 3.x
  - Tkinter (GUI)
  - pymysql (MySQL interaction)
  - openpyxl (Excel file handling)
- MySQL (XAMPP Server)
- XAMPP for local MySQL server


📌 Features
- Student registration with course details
- GUI-based form entry using Tkinter
- Data stored in MySQL database
- Data exported to Excel (.xlsx)
- Input validation
- Simple user interface
